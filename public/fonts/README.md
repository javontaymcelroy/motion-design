# Fonts

Latin subsets of the variable fonts, from Google Fonts. Both are licensed
under the SIL Open Font License 1.1.

- `InterTight-Variable.woff2`: Inter Tight (display and headlines)
- `JetBrainsMono-Variable.woff2`: JetBrains Mono (labels, numbers, handles)

To change brand fonts, drop new `.woff2` files here and update
`src/theme/fonts.ts` and the typography section of `DESIGN.md`.
